# NOVAURAH

My very own online e-commerce store for my Clothing brand called
"Novaurah" (not real but could be); made for the sake of practicality!

![SCREENSHOT](image.png)

## FEATURES
-Product grid built from a Javascript array
- Filter bar (All, Men, Women, Accessories, Oudoor Wear)
- Shopping cart with live count, total and checkout
- Cart saved in browser with localStorage
- Outdoor wear mode: An evening scene made from CSS gradient and shapes
